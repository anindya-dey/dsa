## Problem

`height[i]` is the height of a bar of width 1. After rain, water collects
between bars. Return how many units of water are trapped.

**Constraints**

- `1 <= height.length <= 2 * 10^4`
- `0 <= height[i] <= 10^5`

**Example**

```text
Input:  height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
Output: 6
```

## Brute force

The water above bar `i` is limited by the tallest bar to its left and the
tallest bar to its right. It rises to the lower of those two, minus the
bar's own height. Compute both maxima for every bar.

```cpp
int trapBrute(const std::vector<int>& height) {
    int n = static_cast<int>(height.size());
    int water = 0;
    for (int i = 0; i < n; ++i) {
        int leftMax = 0;
        int rightMax = 0;
        for (int j = 0; j <= i; ++j) {
            leftMax = std::max(leftMax, height[j]);
        }
        for (int j = i; j < n; ++j) {
            rightMax = std::max(rightMax, height[j]);
        }
        water += std::min(leftMax, rightMax) - height[i];
    }
    return water;
}
```

That per-bar formula is the key insight, and it is correct. The scans are
the waste. Each bar rescans the whole array, so the total is O(n²).

## Optimal: fill basins as their right wall arrives

Process bars left to right and keep a stack of indices whose heights
*decrease* from bottom to top. The stack holds the bars still waiting for
a right wall.

When a taller bar arrives, it is the right wall of a basin. Pop the top
bar. That is the basin's floor. The new top of the stack is the left
wall. Water fills that basin up to the lower wall, across the width
between the walls. Keep popping while the new bar is taller, because each
pop fills one horizontal layer.

```cpp
int trap(const std::vector<int>& height) {
    std::vector<int> stack;                       // indices, heights decreasing
    int water = 0;
    for (int i = 0; i < static_cast<int>(height.size()); ++i) {
        while (!stack.empty() && height[i] > height[stack.back()]) {
            int floor = height[stack.back()];
            stack.pop_back();
            if (stack.empty()) {
                break;                            // no left wall: water spills
            }
            int left = stack.back();
            int width = i - left - 1;
            int depth = std::min(height[left], height[i]) - floor;
            water += width * depth;               // one horizontal layer
        }
        stack.push_back(i);
    }
    return water;
}
```

The brute force counts water in vertical columns. The stack counts it in
horizontal layers. Both add up to the same total. Every index is pushed
once and popped at most once, so the work is linear.

## Complexity

| Approach | Time | Space |
| --- | --- | --- |
| Scan both sides per bar | O(n²) | O(1) |
| Precomputed left and right maxima | O(n) | O(n) |
| Monotonic stack, layer by layer | O(n) | O(n) |
| Two pointers from both ends | O(n) | O(1) |

The two-pointer row is the space-optimal answer. Move inward from the
side with the lower maximum, because that side's water level is already
decided. The stack version is the one that teaches
[monotonic structures](/dsa/patterns/monotonic-structures): a stack that
waits for "the next greater element" is the same tool as
[Daily Temperatures](/dsa/patterns/monotonic-structures/daily-temperatures)
and [Largest Rectangle in Histogram](/dsa/patterns/monotonic-structures/largest-rectangle-in-histogram).
