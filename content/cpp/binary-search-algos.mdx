---
title: "lower_bound & upper_bound"
summary: "Binary search on a sorted range: first >= x, first > x, counting, presence, and insertion points."
---

`std::lower_bound` and `std::upper_bound` from `<algorithm>` binary-search
a **sorted** range in O(log n). They return a position, not a yes or no,
which makes them answer more questions than `std::binary_search`.

## The two boundaries

```cpp
#include <algorithm>
#include <cassert>
#include <vector>

int main() {
    std::vector<int> v = {1, 2, 2, 2, 5};

    auto lo = std::lower_bound(v.begin(), v.end(), 2);  // First >= 2.
    auto hi = std::upper_bound(v.begin(), v.end(), 2);  // First > 2.
    assert(lo - v.begin() == 1);
    assert(hi - v.begin() == 4);
    assert(hi - lo == 3);  // How many 2s.

    auto it = std::lower_bound(v.begin(), v.end(), 3);
    assert(*it == 5);                         // Smallest value >= 3.
    assert(it != v.end() && *it != 3);         // 3 is absent.

    assert(std::lower_bound(v.begin(), v.end(), 9) == v.end());
    assert(std::binary_search(v.begin(), v.end(), 5));
}
```

- `lower_bound(x)` returns the first element `>= x`.
- `upper_bound(x)` returns the first element `> x`.
- Each returns `end()` when no element qualifies: `lower_bound` when every
  element is smaller than `x`, and `upper_bound` when none is larger. Check
  for `end()` before dereferencing.

Both return an **iterator**. Subtract `v.begin()` to get an index.

## Common questions, answered

| Question | Answer |
| --- | --- |
| Is `x` present? | `it = lower_bound(x)`, then `it != end && *it == x` |
| First index of `x` | `lower_bound(x) - begin`, if present |
| Last index of `x` | `upper_bound(x) - begin - 1`, if present |
| How many copies of `x`? | `upper_bound(x) - lower_bound(x)` |
| Where to insert `x` and stay sorted | `lower_bound(x)` |
| Largest element `< x` | the element before `lower_bound(x)`, if that is not `begin` |
| Largest element `<= x` | the element before `upper_bound(x)`, if that is not `begin` |

`lower_bound` alone does not tell you whether `x` exists; it finds where
`x` would go. `std::binary_search` returns just `true` or `false`.

## Traps

**The range must be sorted** in the order the search assumes. For a
range sorted in descending order, pass the same comparator you sorted
with, such as `std::greater<int>()`, as the last argument. A mismatched
order gives wrong answers without any error.

**Use the member versions on sets and maps.** `s.lower_bound(x)` on a
`std::set` or `std::map` is O(log n). The free function
`std::lower_bound(s.begin(), s.end(), x)` compiles but steps through the
tree one node at a time, which is O(n).

Writing the loop yourself is still worth knowing: the
[binary search variants](/dsa/patterns/binary-search-variants) pattern
covers searching over answers, such as the smallest speed that works,
where there is no array to pass to these functions.
