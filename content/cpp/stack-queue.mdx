A **stack** is last in, first out (LIFO): you take back the most recent
item first, like a pile of plates. A **queue** is first in, first out
(FIFO): items leave in the order they arrived, like a line at a shop.
`std::stack` lives in `<stack>` and `std::queue` in `<queue>`.

## The operations

```cpp
#include <cassert>
#include <queue>
#include <stack>

int main() {
    std::stack<int> st;
    st.push(1);
    st.push(2);
    assert(st.top() == 2);  // Most recent.
    st.pop();               // Removes 2; returns nothing.
    assert(st.top() == 1 && st.size() == 1);

    std::queue<int> q;
    q.push(1);
    q.push(2);
    assert(q.front() == 1 && q.back() == 2);  // Oldest is at the front.
    q.pop();                                  // Removes 1; returns nothing.
    assert(q.front() == 2);
    assert(!q.empty());
}
```

Every operation shown is O(1). Two rules catch people out:

- **`pop()` returns nothing.** Read `top()` or `front()` first, then pop.
- **The container must not be empty** when you call `top`, `front`,
  `back`, or `pop`. Doing so is undefined behavior, so check `empty()`
  first, as in `while (!st.empty() && st.top() < x) st.pop();`.

You cannot loop over a stack or queue, or read an element by index. Only
the top, or the front and back, are visible. If you need more, use a
vector or deque directly.

## A queue for breadth-first search

Breadth-first search (BFS) visits a graph level by level, and a queue
keeps the nodes in the order they were found:

```cpp
std::vector<std::vector<int>> adj = {{1, 2}, {3}, {3}, {}};
std::vector<int> dist(adj.size(), -1);
std::queue<int> frontier;
dist[0] = 0;
frontier.push(0);
while (!frontier.empty()) {
    int u = frontier.front();
    frontier.pop();
    for (int v : adj[u]) {
        if (dist[v] == -1) {
            dist[v] = dist[u] + 1;
            frontier.push(v);
        }
    }
}
assert(dist[3] == 2);
```

Mark a node as seen when you push it, not when you pop it, so it is never
queued twice.

## The underlying container

`stack` and `queue` are **adapters**: they wrap another container and
expose only the stack or queue operations. Both use `std::deque` by
default. You can choose another, such as `std::stack<int,
std::vector<int>>`, which stores the stack in a vector. A queue needs
removal at the front, so it cannot use a vector.

Many solutions skip `std::stack` and use a `std::vector` with
`push_back`, `back`, and `pop_back`. That works the same and also lets you
loop over the contents.

## Related C++ tools

- [std::deque](/cpp/deque) is the default container underneath both.
- [std::priority_queue](/cpp/priority-queue) pops the highest-priority item instead of the oldest.
- [std::vector](/cpp/vector) can serve as a stack with `push_back` and `pop_back`.
