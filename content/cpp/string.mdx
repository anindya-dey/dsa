`std::string` owns a sequence of characters and grows as you add to it,
much like a `std::vector<char>`. It lives in the `<string>` header.
Each character is a `char`, and `size()` counts them in O(1). For
non-ASCII text such as UTF-8, `size()` counts bytes, not visible letters.

## The everyday operations

```cpp
#include <cassert>
#include <string>

int main() {
    std::string s = "hello";
    s += " world";              // Append text.
    s.push_back('!');           // Append one character.

    assert(s.size() == 12);
    assert(s[0] == 'h' && s.back() == '!');
    assert(s.substr(6, 5) == "world");
    assert(s.find("lo") == 3);
    assert(s.find("xyz") == std::string::npos);
    assert(std::string("apple") < std::string("banana"));
}
```

`substr(pos, len)` copies up to `len` characters starting at `pos`, so it
costs O(len). Leave out `len` to take everything to the end. `find` returns the
first matching index, or `std::string::npos`, a special value meaning
"not found". Check for `npos` before using the result as an index.

Like vector, `s[i]` is unchecked and `s.at(i)` throws `std::out_of_range`
for a bad index. `==` compares the text. `<` compares
**lexicographically**: the first differing character decides, and a
prefix comes before a longer string.

## Characters are small numbers

A `char` holds a character code, so you can do arithmetic on it. For
lowercase letters, `c - 'a'` gives 0 for `'a'` up to 25 for `'z'`, which
is how letter-count arrays are indexed. For digits, `c - '0'` gives the
digit's value, and `'0' + d` turns a digit back into a character.

```cpp
std::string word = "Cab9";
int counts[26] = {};
for (char c : word) {
    if (std::isalpha(c)) ++counts[std::tolower(c) - 'a'];
}
assert(counts[0] == 1 && counts[1] == 1 && counts[2] == 1);
assert(word[3] - '0' == 9);
```

The `<cctype>` functions `std::isalpha`, `std::isdigit`, `std::isalnum`,
`std::isspace`, `std::tolower`, and `std::toupper` classify and convert
single characters. They are safe for plain ASCII text such as LeetCode
input; for other bytes, cast the `char` to `unsigned char` first.

## Building strings efficiently

`s += x` and `s.push_back(c)` append in amortized O(1) per character.
`s = s + c` builds a whole new string each time, so doing it in a loop
costs O(n²). Prefer appending. The algorithms from `<algorithm>` work on
strings too: `std::reverse(s.begin(), s.end())` reverses in place, and
`std::sort(s.begin(), s.end())` sorts the characters, a common way to
compare anagrams. `std::string(3, 'x')` creates `"xxx"`.

Pass a string you only read as `const std::string&` to avoid a copy.
A `std::string_view` (C++17, `<string_view>`) also reads text without
copying, but it does not own the characters: the original string must
outlive it.

## Numbers and words

```cpp
assert(std::to_string(42) == "42");
assert(std::stoi("-17") == -17);
assert(std::stoll("10000000000") == 10000000000LL);

std::istringstream in("the quick fox");
std::vector<std::string> parts;
std::string part;
while (in >> part) parts.push_back(part);  // Splits on whitespace.
assert(parts.size() == 3 && parts[2] == "fox");
```

`std::to_string` formats a number; `std::stoi` and `std::stoll` parse an
`int` or `long long`. They stop at the first character that is not part of
the number, so `std::stoi("42x")` returns 42. They throw if no number can
be read or if it does not fit. Reading words from a `std::istringstream` (in `<sstream>`) with
`>>` splits text on whitespace. To split on another character, use
`std::getline(in, part, ',')`.
